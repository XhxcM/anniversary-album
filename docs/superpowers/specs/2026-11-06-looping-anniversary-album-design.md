# 自动循环纪念相册设计规格

状态：对话设计已确认；本文待用户审阅。本文取代 2026-10-30 规格中与自动播放、交互和布局冲突的内容。

## 目标与素材

为女友制作以微信内置浏览器观看为主的纪念日礼物。视觉参考用户提供的视频，重点对照深色星空、照片卡片的构图与密度、六种造型和转场节奏；不复制视频平台界面、品牌、照片标签或逐张文案。以视觉接近 95% 为主观目标，不把它作为可以精确量化的保证。正式照片、开场合照、音乐、时间线日期和信件由用户之后提供。

70–90 张原照片统一以约 3:4 竖向卡片呈现，默认居中裁切；原图不变，人物被切到时允许单独调整裁切中心。目标约 100 张卡片：所有照片至少出现一次，再从照片池中等概率、无放回地选取需要重复的照片，每张最多出现两次；因此重复机会相同。页面初始化后固定卡片与照片的对应关系，整个访问期间和跨循环都不重新抽图；固定种子确保同一照片列表刷新后结果稳定。低性能降级时可均匀减少可见卡片，但不破坏原图和完整素材。

## 开场与持续界面

- 顶部从加载起显示 `OUR LITTLE UNIVERSE`、`从心动开始的每一秒` 及实时的天、时、分、秒。起点为 2025-12-14 00:00:00 Asia/Shanghai，依据当前时间差计算，每秒刷新，恢复前台时立即校正。无副标题、左上品牌或分享入口。
- 中央显示三四张错位叠放的照片卡片，最前为用户之后指定的合照；其余开场照片也由用户指定，未提供时使用占位。以轻微呼吸和漂浮提示互动，不显示文字提示。
- 点击屏幕空白处后，照片从卡片堆后分层飞出，约 3 秒展开为双心；同一手势尝试启动音乐及适用的全屏、横屏请求。实际展开受横屏条件约束。控件点击不触发开场。
- 开始后右下角“我们的时间线”“写给你”依次上浮、淡入并轻微回弹；按钮点击有轻微缩放反馈。左下角提供音乐暂停/继续按钮，暂停保留播放位置。
- 背景为暗紫黑、蓝黑与柔光，伴随缓慢漂浮的爱心和光斑。鼠标移动或触摸滑动产生限量爱心轨迹；触摸空白产生少量散开粒子，按钮操作不触发。减少动态效果时关闭跟随粒子并采用静态或低动态展示。

## 自动照片循环

同一 Three.js 舞台、同一批卡片连续运行，无章节、手动切换、单张点击、悬停或灯箱。顺序固定：

1. 立体双心：我的每一次心跳，都在悄悄靠近你
2. 照片矩阵：那些普通的日子，因为有你才值得收藏
3. 球形聚拢：零散的瞬间，慢慢围成了我们的世界
4. 横向波浪长廊：一起走过的路，回头看全是温柔
5. 立体圆环：时间绕过一圈又一圈，我还是最喜欢你
6. 半圆柱照片墙：故事没有终点，我们还会拍下许多个明天

每个造型稳定停留约 6 秒，平滑过渡到下一造型约 2.5 秒，一轮约 51 秒；末尾回到双心并循环。位置、旋转、缩放及景深平滑插值，保证循环衔接。底部情话随造型交叉淡化，装饰波形在音乐播放时柔和起伏、暂停时停止，不分析真实频谱。页面后台暂停渲染与造型计时，回到前台从原进度继续；音乐依浏览器实际行为处理。弹窗打开时前台照片、音乐和计时继续。

## 时间线与信件

右下角两个按钮各自打开弹窗，一次只打开一个。弹窗使用半透明暗色遮罩，内容可在手机横屏内部滚动；打开和关闭要有键盘焦点管理、可见关闭按钮和 Esc 支持。时间线按配置顺序显示编号、日期、标题和简短说明：第一次相遇、第一次一起吃饭、第一次看电影、第一次旅行等，结尾为“我们还有很多第一次没一起去做”。日期默认 `YYYY.MM.DD`；不确定时允许自由文本，未来节点可写“未完待续”。

信件按钮先显示密码框，不提供提示；解密失败显示“密码不对，再想想看”。信件正文与落款由用户之后提供。使用随机盐值及 IV，通过标准密码派生函数生成密钥并用 AES-GCM 加密；公开资源只包含解密必需的参数与密文，不包含明文或密码。使用 HTTPS 和浏览器 Web Crypto 解密。关闭弹窗清除界面及应用持有的明文、密钥引用；JavaScript 无法保证物理内存被立即擦除。每次重新打开都需输入密码。短密码存在离线穷举风险；前端延迟不构成有效的离线防护。明文信件、原图和密码不进入版本库或部署产物。

## 手机、音乐与降级

主要验收 iPhone 与安卓微信，桌面 Chrome/Edge 供预览。必须横屏，无竖屏继续入口。竖屏显示旋转提示；点击开场时可在支持的浏览器尝试全屏及横屏锁定，失败则手动旋转，横屏后继续。浏览器不保证允许自动锁定或全屏。

音乐由开场手势尝试播放并循环；如果旋转后浏览器拒绝播放，显示播放按钮让用户主动启动。音乐缺失或播放失败不阻断相册。系统减少动态效果、WebGL 不可用或持续低帧率时采用可访问的低动态照片墙或降低画质/可见数量；保留计时器和弹窗。竖屏提示或后台状态下暂停 3D 渲染，恢复后继续。

## 工程边界与发布

基于现有 Vue 3、Vite、Three.js 工程调整，不引入不必要的运行时依赖。复用素材处理、渲染预算与降级机制；重构原章节导航与内容结构，以便单一照片池驱动阵型。保留用户已有配置和原始素材，迁移前检查并说明兼容方式。照片副本压缩并去除 EXIF/定位信息，原图不上传。

目标为非公开 HTTPS 链接，随机地址，保留 noindex 和 robots.txt；任何持链接者仍可查看、保存照片和时间线，只有信件正文加密。实际部署及账户操作需按用户届时的授权处理。

## 验收标准

- 六种造型按约定顺序、时长连续过渡，末尾无突兀跳回；卡片照片在整个循环中不变。70、80、90 张照片下验证全部至少出现一次、重复最多一次且抽取均衡。
- 开场合照位置、展开动画、计时准确性及跨后台恢复符合描述；按钮在点击后动态出现，弹窗期间动画继续。
- 时间线滚动和关闭可用；信件正确密码解密、错误密码失败、关闭后再次要求输入；构建产物无明文信件或密码。
- 音乐手势启动、失败恢复、暂停续播和循环可用；缺失音乐与图片不会使页面空白。
- 自动测试和生产构建通过；在桌面与至少一台 iPhone 微信、一台安卓微信上核对横屏、开场、性能、弹窗、音乐和循环。
- 使用真实素材对照参考视频关键帧，逐项检查布局、照片密度、景深、造型和节奏；记录主观差异，不宣称自动测得 95%。
